# Keyword list for Google Ads Keyword Planner

Built from the product range confirmed in [PRODUCT-SPECS.md](PRODUCT-SPECS.md) and the search vocabulary in [profile.md](profile.md). Every term below maps to a page that now exists, or to one worth building if the volume justifies it.

## Before you start

**Settings that matter more than the list.** In Keyword Planner set **Location: Cyprus** (not "Cyprus and similar"), and **Language: Greek** for the Greek block, then run the English block separately with **Language: English**. Leaving the location at a default will return Greek-market volume and mislead you badly — Greece is roughly forty times the population.

**Expect small numbers, and do not dismiss them.** Cyprus has under a million people and this is a niche trade. A term returning **10–100 searches a month is genuinely good** here; 1,000+ almost certainly means the tool is showing you Greece or a broader match. A query with 20 searches a month and clear buying intent is worth more than 500 informational searches for "flag of Cyprus".

**Without an active campaign, Keyword Planner shows wide ranges** (e.g. "10–100") rather than exact figures. That is enough to rank terms against each other, which is all you need.

**Check the accent-free spelling too.** Many people type Greek without accents, and some Cypriots search in Greeklish. Keyword Planner usually merges these, but if a term returns nothing, try the variants in the last section before concluding there is no demand.

**Without accents** — how a lot of people actually type:

```

λαβαρα σχολειων

```

```

```

**Singular and plural**, which Keyword Planner does not always merge:

```

λάβαρο / λάβαρα
πηλήκιο / πηλήκια
```

## What to do with the numbers

Sort by volume, then read each term against three questions:

1. **Does a page already target it?** Most do. If a high-volume term has no page, that is the next page to build.
2. **Is the intent commercial?** «κυπριακή σημαία» is largely people wanting a picture of the flag; «αγορά σημαίας» is someone with a wallet out. Volume without intent is a trap — the same trap as `flags cyprus`, which is dominated by Wikipedia and stock-photo sites.
3. **Is it seasonal?** Parade terms spike around 25 March, 1 April, 1 October and 28 October. Keyword Planner will show the monthly breakdown; check it before judging an annual average.

Bring the numbers back and I will map them against the current pages and say where the gaps are.

**A note on paid search.** This list is for *research*, not necessarily for spending. With no published prices and a phone-only sales process, paid clicks convert worse than they would for a competitor with a shop front and a checkout. The volumes are most useful for deciding what to write next.
